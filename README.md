# The Met Museum Landing

The Met Museum Landing is a responsive promotional website for The Metropolitan Museum of Art. It highlights museum hours, current exhibitions, online experiences, and contact information in a clean single-page layout built with semantic HTML, SCSS, and JavaScript.

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/liena-grytsyna/the-met-museum-landing.git
cd the-met-museum-landing
```

2. Install dependencies:

```bash
npm install
```

3. Run the project locally:

```bash
npm run dev
```

You can also use:

```bash
npm start
```

4. Build the production version:

```bash
npm run build
```

## Features

- Responsive single-page layout for desktop and mobile screens
- Hero section with branded museum visuals
- Sections for museum hours, exhibitions, and online exploration
- Contact area with phone links and map links
- Mobile navigation menu and smooth in-page section linking
